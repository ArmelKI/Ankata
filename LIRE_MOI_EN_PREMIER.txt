ANKATA - LIRE MOI EN PREMIER

Ce fichier donne l'ordre de lecture et les commandes minimales pour démarrer.

1) Commencer ici
- Ouvrir QUICK_START.md
- Puis lire README.md

2) Selon votre besoin
- Déploiement: DEPLOYMENT_GUIDE.md
- Firebase: FIREBASE_SETUP_GUIDE.md
- Paiement: PAIEMENT_SETUP_GUIDE.md
- Vue d'ensemble des docs: INDEX.md

3) Démarrage local rapide

Backend:
  cd backend
  cp .env.example .env
  npm install
  npm run db:migrate
  npm run dev

Mobile:
  cd mobile
  flutter pub get
  flutter run

4) Points importants
- La documentation historique a été nettoyée pour éviter les doublons.
- Les documents conservés sont ceux utiles à l'exécution du projet.
- Les logos compagnies restent dans mobile/assets/images/companies.
- Supabase reste la source de vérité pour le schéma production.
